# Predicting-F1-Pit-Stops-Blend
Stable high-score machine learning solution for Kaggle Playground Series S6E5: Predicting F1 Pit Stops. The project uses fold-safe feature engineering, original dataset augmentation, CatBoost/XGBoost/LightGBM models, OOF validation, and rank-based blending to predict pit stops on the next lap.
